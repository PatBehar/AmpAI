# AmpAI fonts

Codec Pro is the approved AmpAI typeface. No licensed Codec Pro files were supplied with this local review package, so the page uses the documented fallback stack:

```css
"Codec Pro", "Avenir Next", "Helvetica Neue", Arial, sans-serif
```

The fallback is intentionally documented and must be replaced with the approved licensed Codec Pro files before final publication if they become available.
